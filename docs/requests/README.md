# Change requests

Need a change in a file you do not own? Do not edit it. Write the request in `docs/requests/<YourName>.md`
(you own that file) using this shape, push it to your branch, and tell the owner. Shared files go to Je.

```
## <date time> -> <Owner>: <one-line title>
File: <path>
Why: <what you are blocked on>
Change: <exact function / field / behaviour you need>
Until then: <how you are coding around it>
Status: open
```

The owner replies by changing their file on their branch (or Je on main for shared files) and setting
`Status: done <commit>` in your request through a message to you; you update your own file.
