No leakage between training and test

The search index holds only knowledge-base tickets, so a draft can never quote the answer to the ticket being scored.

  • ✓Pass0 holdout tickets in the search index
  • ✓Pass0 indexed tickets from outside the knowledge base
  • ✓Pass0 ticket ids shared between the two splits
  • ✓PassKnowledge-base tickets carry their resolved answers; holdout answers are never indexed

1 holdout ticket has the same body text as a knowledge-base ticket (a duplicate in the source data). It is reported, not removed.

How we tested

  1. Split once, 80/20. 22,869 knowledge-base tickets train the classifier and fill the search index; 5,718 holdout tickets are set aside.
  2. Tune on validation only. Gate thresholds and calibration are fit on a validation slice of the knowledge base (2,287 tickets).
  3. Score the holdout once. Holdout labels are read only to score predictions made from raw text.
